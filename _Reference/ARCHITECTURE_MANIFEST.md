# ARCHITECTURE MANIFEST
## Master-Static-Template: The Golden Architecture DNA

> **Source Repository:** `Master-Static-Template`  
> **Purpose:** Production-grade Next.js 16 boilerplate for high-performance industrial B2B sites  
> **Target Market:** South Africa / Cape Town deployment (af-south-1 / cpt1)  
> **Philosophy:** Zero-runtime CSS, Server-first architecture, Military-grade security, Critically damped motion physics

## 1. THE STACK (Next.js 16 Specifics)

### **Framework & Runtime**
- **Next.js**: `16.1.6` (App Router ONLY)
- **React**: `19.2.3` (includes React Compiler via Babel plugin)
- **TypeScript**: `^5` (strict mode enabled)
- **Node Target**: `ES2017`

### **App Router Confirms**
✅ **Full App Router** - All routing via `/src/app` directory  
✅ **Server Components by default** - Client Components explicitly marked with `"use client"`  
✅ **Metadata API** - Native `export const metadata: Metadata` in `layout.tsx`  
✅ **Route Handlers** - API routes using `route.ts` convention (e.g., `/api/audit/route.ts`)  
✅ **No Pages Directory** - Pure App Router architecture

### **Data Fetching Strategy**
- **NO external libraries** (no SWR, no React Query)
- **Native `fetch` with Next.js 16** - Server Components fetch data directly
- **API Route Handlers** - POST/GET handlers using `NextResponse` for complex server logic
- **Server Actions** - Not currently implemented (opportunity for enhancement)

### **React 19 Features Utilized**
- **React 19.2.3** with `react-jsx` transform
- **React Compiler** - Enabled via `babel-plugin-react-compiler: 1.0.0`
- **Automatic Batching** - Implicit in React 19
- **Transitions** - View transitions via `viewTransitionName` prop (see `page.tsx:34`)

## 3. STYLING & THEME ENGINE

### **⚠️ NOT Tailwind - Using Panda CSS (Zero-Runtime)**

This architecture uses **Panda CSS** (`@pandacss/dev`), which:
- Generates atomic CSS at **build time** (zero-runtime overhead)
- Uses TypeScript for **type-safe styling**
- Outputs to `/styled-system` directory
- Has similar syntax to Tailwind but with inline object styles

### **Build Process**
```json
// package.json
"scripts": {
  "build": "panda codegen && next build"
}
```
> ⚠️ **CRITICAL:** `panda codegen` MUST run before `next build`

### **Panda CSS Usage Pattern**

```tsx
import { css } from "../../../styled-system/css";

const myComponent = () => (
  <div className={css({
    padding: "sectional",      // Uses token from panda.config.ts
    bg: "accent.DEFAULT",       // Uses semantic token
    fontSize: "lg",             // Fluid Golden Ratio typography
    _hover: {                   // Pseudo-selectors supported
      transform: "scale(1.05)"
    }
  })}>
    Content
  </div>
);
```

```typescript
export function proxy(request: NextRequest) {
  const response = NextResponse.next();

  // Security Headers
  response.headers.set("X-Frame-Options", "DENY");
  response.headers.set("X-Content-Type-Options", "nosniff");
  response.headers.set("Referrer-Policy", "strict-origin-when-cross-origin");
  response.headers.set(
    "Content-Security-Policy",
    "default-src 'self'; script-src 'self' 'unsafe-eval' 'unsafe-inline' https://challenges.cloudflare.com; ..."
  );

  // Geo-routing for South Africa
  const country = request.headers.get("x-vercel-ip-country") || "ZA";
  response.headers.set("x-compliance-standard", country === "ZA" ? "POPIA" : "GDPR");
  response.headers.set("x-deployment-region", "af-south-1");

  return response;
}
```

> **Rule:** Security headers should be set in a proxy function, NOT in `next.config.ts` headers.

## 5. CODING STANDARDS

### **TypeScript Patterns**

#### **Interfaces vs Types**

```tsx
// ✅ PREFER: Interfaces for component props
interface ButtonProps {
  children: ReactNode;
  onClick?: () => void;
  className?: string;
  variant?: "primary" | "outline" | "ghost";
  size?: "sm" | "md" | "lg";
}

// ✅ ACCEPTABLE: Types for unions/literals
type Variant = "primary" | "outline" | "ghost";
```

> **Rule:** Use **interfaces** for component props. Use **types** for unions, literals, and utility types.

#### **Strict Mode Enabled**

```json
// tsconfig.json
{
  "compilerOptions": {
    "strict": true,
    "target": "ES2017",
    "jsx": "react-jsx",
    "moduleResolution": "bundler"
  }
}
```

### **Zod Validation (Zero-Trust API)**

```tsx
// src/lib/security.ts
import "server-only";  // ✅ CRITICAL: Prevents client-side import
import { z } from "zod";

export async function validateRequest<T>(schema: z.ZodSchema<T>, data: unknown): Promise<T> {
  const result = schema.safeParse(data);
  if (!result.success) {
    throw new Error(`Validation failed: ${result.error.message}`);
  }
  return result.data;
}

// src/app/api/audit/route.ts
const AuditRequestSchema = z.object({
  email: z.string().email(),
  domain: z.string().url(),
  turnstileToken: z.string(),
});

export async function POST(request: Request) {
  const body = await request.json();
  const data = await validateRequest(AuditRequestSchema, body);  // ✅
  // ...
}
```

> **Rule:** ALL API route inputs MUST be validated with Zod schemas. NO exceptions.

### **Server-Only Module Isolation**

```tsx
// src/lib/security.ts
import "server-only";  // ✅ MUST be first import

// Any attempt to import this file on the client will throw a build error
```

> **Rule:** ALL `/lib` files MUST import `"server-only"` as the first line.

### **Client Component Marking**

```tsx
// ✅ CORRECT: Explicit "use client" directive

import { motion } from "framer-motion";

  // Interactive component with hooks/event handlers

```

> **Rule:** ANY component using hooks, event handlers, or browser APIs MUST have `"use client"` at the top.

## 6. ARCHITECTURAL PATTERNS & CONVENTIONS

### **Component Architecture**

#### **Atomic Design Hierarchy**

```
atoms/       → Pure UI primitives (Button, Input, Typography)
  ├─ No business logic
  ├─ Highly reusable
  └─ Can be Server or Client Components

molecules/   → Composite interactive widgets (TerminalBox, TrustBadge)
  ├─ Combine 2-3 atoms
  ├─ Usually Client Components ("use client")
  └─ Self-contained functionality

organisms/   → Feature blocks (EclipseHero, ContactSection)
  ├─ Combine molecules + atoms
  ├─ Mix of Server and Client Components
  └─ Represent complete UI sections
```

#### **Server vs Client Component Decision Matrix**

| Criteria | Server Component | Client Component |
|----------|------------------|------------------|
| Uses `useState`, `useEffect` | ❌ | ✅ |
| Event handlers (`onClick`, etc.) | ❌ | ✅ |
| Framer Motion animations | ❌ | ✅ |
| Fetch data from API | ✅ | ❌ (use Server) |
| Pure rendering of static content | ✅ | ❌ (unnecessary) |
| Access `localStorage`, `window` | ❌ | ✅ |

#### **The "Children Prop" Pattern**

```tsx
// ✅ Pass Server Component as children to Client Component
// layout.tsx (Server Component)
export default function Layout({ children }) {
  return (
    <ClientSideWrapper>
      {children}  {/* Server Component rendered inside */}
    </ClientSideWrapper>
  );
}
```

> **Rule:** To maintain server boundaries, pass Server Components as `children` to Client Components.

### **API Route Pattern (Route Handlers)**

```typescript

    if (!isValid) {
      return NextResponse.json({ error: "Security verification failed" }, { status: 403 });
```

## 10. CRITICAL GOTCHAS & WARNINGS

⚠️ **PANDA CSS CODEGEN**  
Run `panda codegen` before every build. The build script does this automatically, but manual builds require it.

⚠️ **STYLED-SYSTEM IS AUTO-GENERATED**  
NEVER edit files in `/styled-system` - they will be overwritten. Edit `panda.config.ts` instead.

⚠️ **SERVER-ONLY IMPORTS**  
ALL `/lib` files must import `"server-only"` first. This prevents accidental client-side imports.

⚠️ **"USE CLIENT" DIRECTIVE**  
Framer Motion components REQUIRE `"use client"`. Missing this will cause hydration errors.

⚠️ **8PX GRID DISCIPLINE**  
Button heights MUST be multiples of 8 (40px, 48px, 56px). Use spacing tokens, not arbitrary values.

⚠️ **NO SITEMAP/ROBOTS.TXT YET**  
Current codebase lacks `sitemap.ts` and `robots.ts`. Must be added before production.

⚠️ **TURNSTILE STUB**  
`verifyTurnstile()` in `security.ts` is a stub. Replace with real Cloudflare API call in production.

⚠️ **PROXY.TS NOT MIDDLEWARE.TS**  
Security headers are in `proxy.ts`, not the standard `middleware.ts` pattern. Adapt accordingly.
